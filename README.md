# Payflow

React, TypeScript, and Vite app using [shadcn/ui](https://ui.shadcn.com/), Tailwind CSS v4, Radix UI, and Lucide icons.

## Development

```sh
npm install
npm run dev
```

## Add a shadcn/ui component

Use the shadcn CLI to copy a component into the project:

```sh
npx shadcn add accordion
```

Available components and usage examples are in the [shadcn/ui documentation](https://ui.shadcn.com/docs/components).
